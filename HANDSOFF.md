## What this is

Custom-firmware + reverse-engineering project for the **Ninebot G30 Max** e-scooter. The stock ESC motor controller is replaced by a **VESC**; the BLE dashboard and BMS keep their stock hardware but get custom firmware to restore the original feature set, expose the VESC App over BLE, and remove the speed cap. A custom ECDSA-P256-signed secure bootloader is being developed.

### What Claude remembers about this project

- **battery-voltage-target-open** — Open design decision — target battery voltage/cell-count for the VESC+Daly G30 build
- **ble-dashboard-auth-encryption2** — G30 dashboard BLE auth is Ninebot 'Encryption2' (Gen3 5AB5, board 0x04); cloud token is a dead end
- **c542rc-dashboard-tap** — NUCLEO-C542RC taps the dashboard internal plug via Arduino A0=PA0 / A2=PA4 for dumping/RE
- **dashboard-simulators** — How the G30 dashboard firmware is simulated (functional sim + Renode)
- **rc-servo-bootloader-reference** — RC-Servo project is the bootloader reference; Ninebot adopts its layout + bl_updater + migration apps
- **stock-pack-is-10s6p** — Stock G30 Max battery pack is 10S6P (60 cells), not 10S3P
- **update-transport-nbu** — Ninebot bus is one-wire half-duplex; firmware-update transport is NBU (framed), not XMODEM
- **verify-firmware-safe** — After every firmware change, run the verify-safe gate (no brick + update path + secure boot)
- **work-until-done** — Finish the task autonomously — don't stop at milestones, don't ask back, do everything needed
